上传方法
1. 先在 GitHub 仓库中选择 Code → Download ZIP，保留现有版本备份。
2. 解压本次交付的 iris-place.zip。
3. 打开 iris-place 仓库，选择 Add file → Upload files。
4. 将解压文件夹内的全部 .html、styles.css、site.js 拖入上传区。
   上传的是文件，不是外面的 iris-place 文件夹；index.html 应位于仓库最外层。
5. 保存修改（Commit changes）。这会替换首页，并触发已有 GitHub Pages 发布。
6. 部署完成后刷新原网站，测试：首页 → 两门课程 → 示例笔记 → 返回课程。

本次包含：首页、两门课程页、两篇示例笔记、共享样式和交互。
中英文切换涵盖本次示例内容；以后添加的真实笔记需要单独提供译文。
